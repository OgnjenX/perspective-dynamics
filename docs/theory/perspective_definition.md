# Perspective: Level 1 operational definition

In this phase, a perspective is a named control condition over a shared relational world. It selects a reusable family of schemas: prerequisites, relational effects, and action interpretations. World facts and available objects remain unchanged when the perspective changes.

Two perspectives are distinct only when they produce a reproducible difference in the relational transitions available under the same input. A label, a new fact, or a different random seed is not by itself a perspective.

The Level 1 model implements perspective as schema indexing, not as a neural state or literal coordinate transform. This is an algorithmic definition chosen to make the claim testable. It does not establish that biological cognition uses explicit perspective labels.
