# Falsification criteria for Level 1

The revised Level 1 principle is weakened or rejected in a prospective matched evaluation if:

1. composition does not solve tasks whose route is split across schemas;
2. single-perspective access solves the same tasks equally well;
3. pooled facts without chaining solve them equally well;
4. success depends on hidden goal facts, an oracle route, or an unreported capacity difference;
5. provenance cannot identify the intermediate relation enabling each cross-perspective step;
6. the effect disappears across held-out object names and schema orderings; or
7. random combinations perform as well as structured effect-to-prerequisite matching.

Passing the toy test is not confirmation of the broad creativity hypothesis. It establishes only that the proposed computational operation is implementable and has a clear target for stronger experiments.
