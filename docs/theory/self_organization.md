# Self-organization

Here, self-organization means that category prototypes and memberships emerge
from repeated local updates rather than being supplied as schema rules. The
input features, learning objective, distance function, and update rules remain
designed by the experimenter.

EXP011 compares random assignment, competitive learning, and a one-dimensional
self-organizing map (SOM). The SOM preserves neighborhood cooperation during
training; competitive learning updates only the winning prototype.

This is not unrestricted concept discovery. Success establishes only that the
chosen experience representation contains enough regularity for unsupervised
categories to support held-out transfer.
