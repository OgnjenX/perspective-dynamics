# Emergence of a trajectory

In this project, an emergent trajectory is a useful ordered sequence of relational actions whose complete sequence is absent from every individual schema family, while its component transitions are available for composition.

For Phase 1, “emergent” is a structural description, not a claim about irreducibility or consciousness. The complete route `assemble → secure → reach` is not stored as one schema; it is generated by chaining schemas from distinct perspectives.

An emergence claim requires provenance, held-out task instances, matched controls, and a pre-specified success criterion. The present prototype demonstrates the mechanism on a synthetic task only.
