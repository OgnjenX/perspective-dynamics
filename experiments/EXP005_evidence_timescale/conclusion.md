## Status

Held-out confirmation completed on 2026-08-13: 16,800 runs across 200 unseen seeds, 12 block lengths, and seven evaluation thresholds. Sixteen unit tests passed.

Spearman rank correlation between ordered evidence threshold and selected optimal dwell was 0.99103121, exceeding the preregistered 0.8 criterion. There were zero adjacent downward reversals, passing the maximum-one criterion.

## Conclusion

Within this controlled perspective-switching model, the productive dwell timescale is calibrated to evaluation demand: stricter evidence thresholds require longer uninterrupted processing in a perspective before switching policy can recognize progress and exploit that frame. Neither maximal switching speed nor one fixed dwell is optimal across evaluation regimes.

This is a reproducible, held-out model result rather than a post-hoc pattern. It refines the project’s metastability hypothesis from “intermediate switching is useful” to a more precise prediction:

> The productive stability–flexibility balance should shift with the evidence required to validate progress.

## Novelty assessment

Related literature addresses the stability–flexibility tradeoff, learned task-switch readiness, autonomy in creative shifting versus dwelling, dynamic creative brain states, and modulation of metastable-state duration. The Week 1/EXP005 search did not identify a direct test tying perspective-specific evidence threshold to an optimal representational dwell timescale. This absence is not proof of novelty; a systematic review is still required.

## Boundaries and alternatives

- Evaluation threshold is a controller parameter and goal activation is supervised task feedback.
- Optimal dwell partly reflects the accumulation kinetics of this specific spreading-activation model.
- Frames remain engineered weighted paths rather than learned semantic or cognitive maps.
- The controller uses an external decision clock; dwell is not yet generated by a biological circuit.
- Generalization across task topology, propagation normalization, noise, and run duration is untested.

## Scientific status

The result is sufficiently interesting to register as the project’s first confirmed model-level finding, but not yet paper-ready. The next tests should derive a self-timed controller and attempt falsification across alternative graph families and dynamics before Brian2 translation.
