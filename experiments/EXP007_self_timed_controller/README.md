# EXP007 — Self-timed mismatch/adaptation controller

## Question

Does evidence-dependent perspective dwell survive when periodic decision blocks are removed and switching is generated by a continuously updated mismatch/adaptation state?

EXP007 targets the strongest remaining artifact explanation for F001. The controller updates on every model step. An intrinsic patience parameter sets adaptation rate, but no periodic evaluation clock dictates segment boundaries; moment-to-moment progress can lengthen a frame’s realized dwell.
