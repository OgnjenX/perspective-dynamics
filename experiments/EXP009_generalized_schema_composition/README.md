# EXP009 — Generalized schema composition

## Purpose

Test whether abstract schemas derived from separate concrete experiences transfer
to held-out objects and environments, and whether any advantage survives
controls for perspective access, pooling, random combination, object names, and
ordinary planning.

This is a prospective design. Results must not be added by changing the frozen
criteria in `hypothesis.md` or `parameters.json`.

## Claim boundary

Role annotations used for abstraction are supplied to the model. EXP009 tests
relational transfer, not unsupervised schema learning. A generic planner that
matches structured composition would show that the current mechanism is not
distinct from ordinary planning.
