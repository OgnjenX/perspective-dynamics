# Prospective hypotheses and criteria

## H9.1 — Held-out relational transfer

Structured composition must solve every original and name-scrambled test case
across three held-out environments. No complete solution trajectory may occur
in any training experience.

## H9.2 — Component necessity

Every single-perspective condition and the all-schema/no-chaining pool must fail
on every test case.

## H9.3 — Name invariance

Each original/scrambled pair must have the same success outcome and the same
sequence of schema and perspective identifiers. No held-out object name may
occur in an abstracted schema.

## H9.4 — Structured alignment

Across the frozen random seeds, structured composition must exceed random
schema selection by at least 0.25 success-rate points under the same number of
schema checks.

## H9.5 — Distinctiveness from ordinary planning

The stronger perspective-integration claim requires a behavioral or
computational difference from an ordinary forward planner given the same
operators, initial facts, goal, and schema-check budget. If the ordinary
planner reproduces the same success and trajectory, EXP009 must explicitly
record that the current operation is ordinary planning under another name.

EXP009 is an overall robust-generalization success only if H9.1–H9.4 pass.
H9.5 is reported separately as the gate for claims beyond ordinary planning.
