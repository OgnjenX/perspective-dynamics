# EXP001 Hypothesis

## Prospective prediction

With dynamics and run duration fixed:

1. peak goal activation will decrease as cue-to-goal path length increases;
2. peak goal activation and success rate will decrease as distractor load increases;
3. successful runs will reach threshold later for longer paths.

## Rationale

The model distributes activation locally over outgoing weighted edges. Each additional edge delays and attenuates the goal signal; distractor branches divert activation away from the valid route.

## Disconfirmation

The qualitative prediction is not supported if goal activation does not decline with distance and distractor load, aside from small seed variability, or if the implementation leaks direct goal information.

## Interpretation limit

Support would validate the baseline implementation and quantify fixed-frame limitations. It would not show that perspective switching improves performance, that the task measures creativity, or that the dynamics are biologically realistic.
