# Experiments

Versioned experiment folders contain their question, prospective predictions, method, parameters, reproducible run instructions, outputs, analysis, deviations, and conclusion.

- `EXP001_baseline_association`: fixed-frame spreading activation across path length and distractor load. This establishes what ordinary association can solve before perspectives are added.
- `EXP002_perspective_matrices`: matched relational frames over identical content. This isolates whether frame-dependent geometry changes goal accessibility before switching is introduced.
